## Mike Moseley

Backend developer working in Go and PostgreSQL. Open to backend, Go, and SQL developer roles, remote or in Roanoke, VA.

### Projects

- **[Redoubt](https://github.com/mike-moseley/Redoubt)**: multiplayer terminal game with a Go server. Tick-based simulation, TCP clients, and a PostgreSQL-backed accounts service (goose migrations, JWT auth).
- **[miSHa](https://github.com/mike-moseley/miSHa)**: Unix shell in C (lexer, parser, executor; fork/exec, pipes, signals), built on my own allocator and data structure libraries.
- **[my-alloc](https://github.com/mike-moseley/my-alloc)**: arena, pool, mmap-backed, and sbrk-backed allocators in C, with unit tests.
- **[c-data-structures](https://github.com/mike-moseley/c-data-structures)**: hash map, ring buffer, linked lists, and dynamic arrays in C.
